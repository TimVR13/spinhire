# Комментарии, готовые к отправке

Один файл — один комментарий под конкретный запуск. Имя: `ГГГГ-ММ-ДД-продукт.txt`.

```bash
python3 scripts/ph_comment.py --comment --dry \
  --url https://www.producthunt.com/products/thousand \
  --text-file tasks/comments/2026-09-10-thousand.txt
```

`--dry` показывает скриншот того, что уйдёт в тред; без него комментарий публикуется и
попадает в `data/ph-comments.json`. Скрипт откажется отправлять текст, который уже
использовали под другим запуском: копипаста на PH работает в минус.

Тексты писались под конкретный продукт и день. Через неделю их отправлять бессмысленно —
проще попросить новые под свежую ленту.
